# Только Да — рабочий прототип

Сайт, который собирает интерактивное приглашение, спрашивает перед отправкой, куда прислать ответ,
и отдаёт получателю только открытку. Ответы приходят отправителю в выбранные каналы и на страницу статуса.

## Запуск

```bash
pip3 install --user flask pywebpush qrcode
python3 app.py
```

Открыть http://localhost:5173

## Страницы

| Адрес | Кто | Что |
|---|---|---|
| `/` | все | лендинг |
| `/create` | отправитель | конструктор, 4 шага, живое превью, попап выбора канала |
| `/sent/<код>?key=…` | отправитель | ссылка, QR, каналы, живой статус ответов |
| `/i/<код>` | получатель | только открытка, 5 экранов |
| `/i/<код>?preview=1` | отправитель | открытка без записи ответов |

## Фронтенд

Без сборки и зависимостей. `static/js/card.js` — движок открытки (превью, автопоказ на лендинге, реальная страница),
`static/js/fx.js` — частицы, появление по скроллу, ripple, `static/css/app.css` — токены и система движения
(`--ease`, `--spring`, `.rise`, `.reveal`). Все анимации отключаются при `prefers-reduced-motion`.

Шрифты лежат локально в `static/fonts` (woff2, только кириллица и латиница, `static/css/fonts.css`),
переменные TTF там же нужны серверу для OG-картинок. Стикеры — свои SVG в `static/stickers`, один стиль
на iPhone и Android. Тёмная тема: кнопка в шапке, выбор хранится в `localStorage`, без выбора следует
системной настройке. OG-картинка приглашения генерируется на сервере по адресу `/i/<код>/og.png`
под тему и заголовок, кэшируется в `data/og`.

## Каналы ответа

Без настройки всё работает в демо-режиме: сообщения пишутся в `data/outbox.log`, а на странице статуса виден лог доставки.
Пуш работает сразу (VAPID-ключи генерируются при первом запуске), но только на localhost или https.

Переменные окружения для боевого режима:

```
PUBLIC_URL=https://example.ru          # чтобы ссылки в письмах были внешними
SMTP_HOST=smtp.yandex.ru SMTP_PORT=465 SMTP_USER=… SMTP_PASS=… SMTP_FROM=…
TELEGRAM_BOT_TOKEN=… TELEGRAM_BOT_USERNAME=…
MAX_BOT_TOKEN=… MAX_BOT_USERNAME=…
VK_GROUP_TOKEN=… VK_GROUP_ID=… VK_GROUP_SCREEN_NAME=…
VAPID_SUB=mailto:you@example.ru
```

Боты Telegram и MAX и сообщество VK привязываются без вебхуков, сервер сам опрашивает их API.

## Данные

`data/db.json` — приглашения и события. `data/outbox.log` — недоставленные сообщения демо-режима.
